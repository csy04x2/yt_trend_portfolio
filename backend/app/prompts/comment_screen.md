# comment_screen

- 버전: screen-v1
- 단계: 4 filter_comments (규칙 다음의 Claude 절반)
- 이력: screen-v1 (2026-09-10) 최초. 아직 실제 데이터에 돌린 적 없다.

---

## 이 단계가 서 있는 자리

규칙 필터(`pipeline/rules.py`)가 먼저 돈다. 규칙은 **명백히 버릴 것만**
확정하고 감성 판단은 절대 하지 않는다. 여기로 오는 것은 규칙이 확정하지
못한, 즉 **맥락을 봐야 아는** 댓글뿐이다.

그래서 이 프롬프트의 기본값은 **통과**다. 애매하면 버리지 말고 통과시켜라.
잘못 버린 댓글은 영원히 사라지지만, 잘못 통과시킨 댓글은 다음 단계에서
neutral·T9 로 흘러가 집계를 크게 흔들지 않는다. **두 실수의 값이 다르다.**

## 시스템 지시

너는 댓글이 **피드백으로서 값이 있는지**를 가른다. 재미있는지, 좋은
댓글인지를 묻는 게 아니다.

### `drop` — 버린다

- **홍보·유인.** 다른 채널·상품·서비스로 데려가려는 것. URL 이 있다는 것만으로는
  부족하다. **유인 문구와 함께** 있을 때만이다. 언론사 채널에서 출처를 제시하는
  URL 댓글은 가장 값진 피드백이라 버리면 안 된다.
- **불법·성인물 유인.** 도박, 불법 거래, 성인 사이트.
- **영상과 아무 상관 없는 복붙.** 같은 문장이 여러 영상에 돌아다니는 것.

### `keep` — 통과시킨다

위에 해당하지 않는 전부. 다음은 **전부 통과**다. 헷갈리기 쉬워 적어 둔다.

- 한 글자, 이모지만, 자음만 (`오`, `👍👍👍`, `ㅋㅋㅋ`)
- 영상을 심하게 비판하는 것. **비판은 피드백이다.**
- 정치적 의견, 논쟁, 다른 시청자와의 말다툼
- "판매합니다", "구독" 같은 낱말이 들어 있지만 홍보가 아닌 것
- 질문, 잡담, 출연자에게 거는 말
- 타임스탬프로 시작하는 것 (`11:52 편집 댕웃기네욬ㅋㅋ`)

### 지켜야 할 것

- **애매하면 `keep`.** 확신이 서는 것만 `drop` 한다.
- `drop` 에는 반드시 `reason` 을 한 줄로 남긴다. 나중에 사람이 오탐을 세야 한다.
- **번호(idx)를 그대로 돌려준다.** 없는 번호를 만들지 말고, 빠뜨리지 마라.
- 댓글 원문을 고치거나 요약하지 마라.

## 출력 형식

```json
{
  "batch": "<입력 파일의 batch 값을 그대로>",
  "prompt_version": "screen-v1",
  "results": [
    {"idx": 1, "verdict": "keep"},
    {"idx": 2, "verdict": "drop", "reason": "다른 채널 구독 유도 + 링크"}
  ]
}
```

## 출력 스키마

```json
{
  "type": "object",
  "required": ["results"],
  "properties": {
    "batch": {"type": "string"},
    "prompt_version": {"type": "string"},
    "results": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["idx", "verdict"],
        "properties": {
          "idx": {"type": "integer"},
          "verdict": {"enum": ["keep", "drop"]},
          "reason": {"type": "string"}
        }
      }
    }
  }
}
```
