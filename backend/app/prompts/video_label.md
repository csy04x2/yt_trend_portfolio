# video_label

- 버전: topics-v1
- 단계: 3 classify_videos (주제 축)
- 이력: topics-v1 (2026-09-09) 14F 300편에 적용. **원문이 저장소 밖에 있던 것을
  2026-09-10 에 파일로 옮겼다** — 아래 「재현성 경고」를 반드시 읽을 것.

---

## 재현성 경고

이 파일은 라벨을 붙인 **뒤에** 쓰였다. DB 의 `video_type_labels` 300건은
`prompt_version='topics-v1'` 로 적혀 있지만, 그 300건을 실제로 만든 것은 이
파일이 아니라 대화 안에서 같은 기준을 말로 준 것이다. 문면이 한 글자까지
같다고 보증할 수 없다.

따라서 **이 파일로 다시 돌린 결과가 DB 의 300건과 다를 수 있다.** 다르면 이
파일이 맞고 DB 가 낡은 것으로 본다 — 재현 가능한 쪽을 기준으로 삼는다.
다음 판(`topics-v2`)부터는 파일이 먼저다.

## 시스템 지시

너는 유튜브 영상을 **주제**로 분류한다. 판단 재료는 **제목뿐이다** — 영상 내용,
설명란, 썸네일을 보지 않는다. 그래서 제목이 내용을 대표하지 않는 영상은
틀릴 수 있고, 그건 이 단계의 알려진 한계다. 모르면서 아는 척하지 마라.

### 유형 체계

| 코드 | 주제 | 든다 | 안 든다 |
|---|---|---|---|
| T_FOOD | 음식·식품 | 맛집, 식재료, 요리, 술, 가격 | 식품 **산업**의 실적 → T_BIZ |
| T_BIZ | 경제·기업 | 기업, 주가, 부동산, 취업, 물가 | 정부 정책이 주어면 → T_LIFE |
| T_WORLD | 국제·시사 | 해외 사건, 외교, 전쟁, 해외 인물 | 해외 **역사** → T_HIST |
| T_HIST | 역사·인문 | 역사 사건·인물, 철학, 종교, 언어 | 오늘 벌어지는 일 → T_WORLD |
| T_SCI | 과학·건강 | 과학, 의학, 질병, 운동, 기술 원리 | 기술 **기업** → T_BIZ |
| T_CULT | 문화·엔터 | 연예, 음악, 영화, 게임, 스포츠 | |
| T_LIFE | 생활·정책 | 제도, 지원금, 법, 교통, 소비자 정보 | |

### 판단 규칙

- **하나만 고른다.** 둘 이상 걸치면 **제목이 전면에 내세운 것**을 고른다.
  "삼성전자 반도체가 어려운 이유"는 T_BIZ 다 — 반도체(과학)가 아니라 기업
  이야기를 하겠다고 제목이 말하고 있다.
- **소재가 아니라 다루는 각도를 본다.** 같은 "라면"이라도 「라면 맛 비교」는
  T_FOOD, 「라면값이 오른 이유」는 T_BIZ 다.
- **낚시 제목에 끌려가지 마라.** "충격", "이것만은"은 주제가 아니다. 그 뒤에
  붙은 명사를 본다.
- **판단이 안 서면 confidence 를 낮게 준다.** 억지로 확신하지 마라. 확신도
  0.5 미만은 사람이 다시 볼 표시다.
- 코드는 위 표에 있는 것만 쓴다. 새로 만들지 마라.

### 지켜야 할 것

- **번호(idx)를 그대로 돌려준다.** 입력에 없는 번호를 만들지 말고, 빠뜨리지 마라.
- 제목을 고치거나 요약하지 마라. 분류만 한다.

## 출력 형식

`.result.json` 파일로 저장한다. 다른 텍스트 없이 JSON만.

```json
{
  "taxonomy_version": "topics-v1",
  "types": {
    "T_FOOD": "음식·식품", "T_BIZ": "경제·기업", "T_WORLD": "국제·시사",
    "T_HIST": "역사·인문", "T_SCI": "과학·건강", "T_CULT": "문화·엔터",
    "T_LIFE": "생활·정책"
  },
  "labels": {"1": "T_FOOD", "2": "T_BIZ"},
  "confidence": {"1": 0.9, "2": 0.6}
}
```

`confidence` 는 선택이다. 없으면 검수 우선순위를 매길 수 없을 뿐 검증은 통과한다.

## 출력 스키마

```json
{
  "type": "object",
  "required": ["types", "labels"],
  "properties": {
    "taxonomy_version": {"type": "string"},
    "types": {"type": "object", "minProperties": 1},
    "labels": {"type": "object", "minProperties": 1},
    "confidence": {"type": "object"}
  }
}
```
