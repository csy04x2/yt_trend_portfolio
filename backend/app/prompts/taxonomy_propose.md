# taxonomy_propose

- 버전: taxonomy-v1
- 단계: 3 classify_videos (유형 체계 제안 — 라벨링보다 먼저)
- 이력: taxonomy-v1 (2026-09-10) 최초. 두 채널에서 손으로 해본 결과를 옮겼다.

---

## 왜 체계를 채널마다 새로 세우는가

두 채널에서 확인했다.

MBC 14F 는 뉴스·시사 채널이라 「음식·식품 / 경제·기업 / 국제·시사 /
역사·인문 / 과학·건강 / 문화·엔터 / 생활·정책」 일곱 갈래가 잘 갈렸다.
그 체계를 예능·브이로그 채널(안녕하세요원이입니다잘부탁드립니다) 107편에
그대로 대보니 **거의 전부가 「문화·엔터」 한 칸으로 뭉쳤다.** 유형이 하나면
유형별 비교가 성립하지 않는다.

그 채널에 맞는 축은 전혀 다른 것이었다 — 「캐릭터·상황극 / 언어·문화 비교 /
사투리·지역 / 게스트·콜라보 / 정보·잡학 / 음악·커버 / 채널 근황·소통 /
비하인드·B컷」. 같은 도구, 다른 자.

**고정 체계를 쓰지 않는 이유가 이것이다.** 체계는 채널이 실제로 만드는
것들의 모양에서 나와야 한다.

## 시스템 지시

너는 채널의 영상 제목 목록을 보고 **그 채널에 맞는 유형 체계**를 제안한다.
아직 개별 영상에 라벨을 붙이지 않는다 — 자를 먼저 만드는 단계다.

### 만들 것

유형 **5~8개**. 코드와 한국어 이름, 그리고 각 유형에 "무엇이 들고 무엇이
안 드는지"를 한 줄씩.

### 좋은 체계의 조건

- **어느 유형도 전체의 절반을 넘지 않는다.** 한 칸에 몰리면 그 축은
  아무것도 가르지 못한다. 몰리면 그 유형을 둘로 쪼갤 축을 찾아라.
- **어느 유형도 3편 미만이 아니다.** 성과 비교의 최소 단위가 안 된다.
  3편 미만이면 옆 유형에 합치거나 「기타」로 흡수한다.
- **경계가 제목만으로 판정 가능하다.** "웃긴 영상 / 진지한 영상"처럼
  영상을 봐야 아는 축은 쓰지 않는다. 다음 단계가 제목만 보기 때문이다.
- **소재가 아니라 다루는 각도로 가른다.** 같은 "라면"이라도 맛 비교와
  가격 분석은 다른 유형이다.
- **채널이 스스로 쓰는 말을 쓴다.** 제목에 반복되는 낱말·시리즈 이름이
  가장 좋은 재료다.

### 하지 말 것

- 다른 채널의 체계를 가져다 쓰지 마라. 이 채널의 제목에서 나와야 한다.
- 유형을 9개 이상 만들지 마라. 잘게 쪼개면 유형마다 표본이 모자란다.
- 「기타」를 크게 만들지 마라. 「기타」가 20%를 넘으면 축을 잘못 잡은 것이다.

### 코너와 겹치지 않게

이 채널의 재생목록에서 읽은 **코너**가 따로 있으면 함께 준다. 코너는 이미
다른 축으로 존재하므로, 주제 체계를 코너 이름과 똑같이 만들지 마라 —
그러면 두 축이 같은 말을 두 번 하게 된다. 코너를 가로지르는 축을 찾아라.

## 출력 형식

```json
{
  "taxonomy_version": "<채널약칭>-topics-v1",
  "types": {
    "W_CHAR": "캐릭터·상황극",
    "W_LANG": "언어·문화 비교"
  },
  "definitions": {
    "W_CHAR": "든다: 설정을 잡고 연기하는 것 · 안 든다: 실제 인물 인터뷰",
    "W_LANG": "든다: 두 나라 말·문화 비교 · 안 든다: 지역 사투리(별도 유형)"
  },
  "rationale": "왜 이렇게 갈랐는지 두세 문장. 어느 유형이 몇 편쯤 될지 추정 포함."
}
```

## 출력 스키마

```json
{
  "type": "object",
  "required": ["taxonomy_version", "types", "definitions"],
  "properties": {
    "taxonomy_version": {"type": "string", "minLength": 1},
    "types": {"type": "object", "minProperties": 5},
    "definitions": {"type": "object", "minProperties": 5},
    "rationale": {"type": "string"}
  }
}
```
